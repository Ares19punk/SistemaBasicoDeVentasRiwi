# Sistema-basico-de-ventas-Riwi
Desarrollar un modulo de gestión de ventas diarias que permita a RiwiTechStories registrar, validar y resumir transacciones de manera estructurada, garantizando la precisión en los cálculos y control básico de las operaciones comerciales,  y estableciendo una base solida para futuras mejoras

## Caputura-de-datos-venta
Esta feature me permitir ingresar la información necesaria para registrar una venta 

### 1. Captura de datos Pbi 419
Se creo interfaz para el ingreso de información: nombre de usuario, valor unitario de producto, la cantidad de prodcuto, estado de cliente (vip o regular)
